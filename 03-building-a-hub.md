# Building a hub

Build a hub by choosing a topic broad enough to have many subtopics but focused enough to own, planning the spokes that cover those subtopics, then writing a hub page that introduces the topic and links out to each spoke. Plan the cluster before writing the pages.

## Choose the topic

The right hub topic is broad enough to support many spoke pages but narrow enough that you can genuinely cover it and own it. Too broad and you cannot treat it thoroughly; too narrow and there are not enough subtopics for spokes. The topic should match what you want to be known for and what your audience searches. Choosing it well is the foundation, because everything in the cluster builds on this central theme.

## Plan the spokes

Before writing, map the subtopics that make up the topic, each of which becomes a spoke. This plan defines the cluster's scope and ensures the coverage is thorough and non-overlapping, with each spoke owning a distinct piece. Planning the spokes up front prevents gaps and redundancy, and it lets you build the cluster deliberately rather than discovering its shape as you go. The spoke plan is the cluster's blueprint.

## Write the hub page

The hub page introduces the topic, summarizes its parts, and links out to each spoke, serving as the organized entry point. It should give a reader a useful overview and a clear path to the depth on each subtopic. The hub is not just a link list; it provides enough context to orient the reader and establish the topic, while routing them onward. A good hub is valuable on its own and as a gateway.

## Build incrementally

A cluster does not have to launch complete. You can publish the hub and an initial set of spokes, then add spokes over time, linking each new one into the cluster as you go. Building incrementally lets you start ranking for the topic and expand coverage steadily. The key is to link each addition into the existing structure, so the cluster grows as a connected whole rather than accumulating disconnected pages. Plan the whole, build it in pieces, keep it connected.
